### 2. 本日の講義：ストーリー設計

#### 2-1. グランドルール（Day3から継続）

- 事業計画は完成品ではなく、ピボット前提の"仮説"として作る
- 顧客に徹底的に向き合い、生の声から課題の真因を掘りにいく
- 机上で悩まず、壁打ちと検証を高速で回す
- 完璧さより前進スピードを重視する

#### 2-2. 今日のあらまし

```
事業計画書は「素材」
  ↓
ピッチデッキという「料理」を作る
  ↓

  ↓

```

#### 2-3. 事業計画書について（Day4で扱う部分）

事業計画書は様々な資料作りの「素」。Day4では特に **2.顧客と課題 / 5.優位性とユニークネス / 補助ツールのSWOT** を扱う。

| 事業計画書 | 補助ツール |
|---|---|
| 1. 事業タイトル（Day1） | 1. 事業の軸（Day2） |
| 2. 顧客と課題（Day2,**4**） | 2. リーンキャンバス（Day2,3） |
| 3. 提供価値と解決策（Day2,3） | 3. バリュープロポジションキャンバス（Day2） |
| 4. ビジネスモデル（Day3） | 4. ビジネスモデルキャンバス |
| 5. 優位性とユニークネス（**4**） | 5. SWOT（**4**） |
| 6. 市場（Day3） | 6. MVV（Day1） |
| | 7. AsIs-ToBe |

#### 2-4. 顧客と課題（ストーリー設計の観点で再訪）

- 想定顧客・想定される課題は、検討とともに変わるので仮置きでよい
- **その代わり「Why me（なぜあなたがこの課題に取り組むのか）」が、ストーリー設計で特に重要**

> KAMAMESHIサンプルの Why me：
> 「製造業の現場で設備故障や部品調達に苦しむ実態を直接見てきた当事者として、製造業全体を救う使命があるため」
> → この "Why me" がピッチの説得力の源になる。

#### 2-5. 優位性とユニークネス（ピッチでの役割）

| 項目 | ピッチでの役割 | KAMAMESHIサンプル |
|---|---|---|
| 優位性 | ソリューションの**納得感・信頼感**を得る | 日本製鉄Grの知見・信頼、理念に共感するメンバーの営業チャネル |
| ユニークネス | **共感・「その手があったか」**を引き出す | 製造業全体での共助を促す理念、製造業版「メルカリ」という唯一無二のPF |

#### 2-6. SWOT

- 強み×機会・弱み×機会・強み×脅威・弱み×脅威のクロスで戦略を導く
- **SWOTはユニークネスや優位性を抽出する参考になる**

> KAMAMESHIサンプル：
> - 強み×機会：自治体と連携したBCPモデル構築（補助金を活用し町工場まで仕組みを行き渡らせる）
> - 強み×脅威：メーカー連携で部品点数を確保
> - 弱み×機会：中古品使用ルールの標準策定で業界標準を取る
> - 弱み×脅威：セキュリティ強化で信頼を獲得

### 3. 自分の「ピッチデッキ」を作る 〜事業計画書を料理する〜

#### 3-1. まずは素材を育てる

これまでの講義を通じて事業計画書が完成していく。
事業計画書は、事業内容を発表する際の「素材」になる。

#### 3-2. 素材を料理する

- 事業計画書は、事業を**理解する資料**としてはそのままでも十分機能する
- しかし経営層・投資家・オーディエンスに理解してもらうには、**発表資料に作り変える**必要がある
- 発表資料には「型」がある → **ピッチデッキ**

#### 3-3. 型を知る（ピッチデッキの構成例）

有名VCが提案する構成をベースに、一旦並べてみることから始める。

| Y Combinator | Sequoia Capital | 500 Startups |
|---|---|---|
| 目的 | 目的 | 目的 |
| 課題 | 課題 | 課題 |
| 解決策 | 解決策 | 解決策 |
| トラクション | なぜ今なのか | 市場規模 |
| 自分の強み | ビジネスモデル | ビジネスモデル |
| ビジネスモデル | 競合 | 強み・他にはない技術 |
| 成長率・市場 | 製品 | 競合 |
| チーム | ビジネスモデル | マーケティング計画 |
| 何をしてほしいのか | チーム | チーム |
| | 財務資料 | 資金計画 |

> 共通して「目的 → 課題 → 解決策」から入る。まずはこの型に乗せてみる。

#### 3-4. ストーリーを意識する

- 型に組んでもしっくりこないことがある
- **想いを込められる流れに組み立てられるか**がポイント
- 流れを意識して組み換え・調整する
