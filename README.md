# 社内アクセラレーションプログラム

## 概要

社内の新規事業創出を目的としたアクセラレーションプログラムの、
運営・進捗管理・事業案管理を行うリポジトリです。

- **期間**：2026年3月〜8月
- **形式**：月1回の講座（全7回）＋ 週次壁打ち
- **参加対象**：新規事業に関心のある社内メンバー（事業案あり・なし両方可）

## このリポジトリでできること

| やりたいこと | 参照先 |
|---|---|
| プログラム全体像を把握したい | `program/00_overview.md` |
| 各回のセッション内容を確認したい | `sessions/` |
| 事業案の現状を確認・更新したい | `ideas/[事業案名]/` |
| 壁打ちのログを残したい | `mentoring/logs/` |
| 新しい事業案フォルダを作りたい | `ideas/_template/` をコピー |

## 進め方

### 事業案フォルダの作り方

```bash
cp -r ideas/_template ideas/idea_001
```

その後、各ファイルを記入する。

### 壁打ちログの残し方

```bash
cp mentoring/logs/_template.md mentoring/logs/YYYY-MM-DD.md
```

### Claude Codeの使い方

CLAUDE.md に依頼パターン例があります。
