## 2. 壁打ちとは

### 定義

> **「話しながら、考えをまとめていく対話術」**
> 位置づけは **「雑談と相談のあいだ」**
> ――石川明（インタビューより）

| | 雑談 | 壁打ち | 相談 |
|---|---|---|---|
| 目的 | 会話そのものを楽しむ | 自分の考えを整理し深める | 答え・判断をもらう |
| 主導権 | 対等 | **話し手が持つ** | 相手に委ねる部分が大きい |
| 結論 | 不要 | **出なくてよい** | 求める |
| 相手の責任 | なし | **答えを出す責任はない** | 答えを出す責任がある |

- 結論を出すことや、誰かの承認を得ることが目的ではない
- 相手という「壁」に考えをぶつけることで、思考が整理される
- 自分の頭だけでなく相手の頭も借りることで、より広く・深く考えられる

### 特徴

- **準備や資料が要らない**。モヤモヤした未完成の考えのまま話し始めてよい
- **数分〜十数分で済む**。相手の負担が小さい
- 目的や具体性がぼんやりした段階から始めてよい
- 書籍の帯の言葉：**「準備をがんばるくらいなら、話す回数を増やせ」**

> 本プログラムのグランドルール「机上で悩まず、壁打ちと検証を高速で回す」「自身の現在地と、もやもやを他人の頭を使って構造化」と同じ考え方。

## 3. 壁打ちの基本の7ステップ

| # | ステップ | ポイント |
|---|---|---|
| 1 | 相手を選ぶ | → 6.「よい壁の条件」 |
| 2 | 声をかける | 「伝える3点」を添える → 4.「話し手のポイント」 |
| 3 | 話し始める | 結論や抽象的なまとめからではなく、具体的な状況から話す（書評ベース） |
| 4 | 相づちや質問が返ってくる | 聞き手は待つ・遮らない → 5.「聞き手の心構え」 |
| 5 | 話題をコントロールする | 主導権は話し手。聞き手も脱線に気づいたら「戻りますか？」と聞いてよい（決めるのは話し手） |
| 6 | 壁打ちを終える | 結論が出ていなくてもよい |
| 7 | リフレクション（振り返り） | 何が整理できたか、次に何をするかを確認する |

> 出典：ステップ名は書籍の紹介・書評より。ポイント欄のうち5〜7は運営による補足。各ステップの詳しい中身は書籍本文で確認のこと。

## 4. 話し手のポイント

### 壁打ちをお願いするときに伝える3点

1. **現在の状況**
2. **壁打ちをお願いする意図**
3. **対話への期待**（何をしてほしいか。聞いてほしいのか、突っ込んでほしいのか、など）

> 「壁打ちさせてください」が目上の人に失礼かどうかという論争があった。
> 「相談」は相手に答えを出す責任を負わせるが、「壁打ち」は答えを求めないという意思表示でもある、という見方もある。
> 3点を添えることで、相手は何を求められているのかがわかり、受けやすくなる。

### 心構え

- **準備しすぎない**。資料をつくり込むより、回数を増やす
- **「わからない」と言える**。石川さんは、一番まずいのは自分の専門性にこだわって「わからない」と認められないことだと述べている。専門外のことを聞くのだから、わからなくて当然と考える
- **すぐに正解を求めない**。すぐに正解を出そうとする人は自分の頭で考えていないので壁打ちにならない（対談相手の秋山ゆかり氏の指摘）
- **主導権は自分にある**。何を話すかは話し手が決める

## 5. 聞き手（「壁」）の心構え

### 基本姿勢

- **うまい助言や的確な答えを出せなくてもよい**
- 相づちを打ちながら、相手の言葉を「壁」として受け止めて返す
- 理想の壁打ち相手は、純粋に「壁」として言葉を跳ね返してくれる人（書評ベース）

### 具体的な振る舞い

| 振る舞い | 内容 |
|---|---|
| **待つ** | 「壁」にとって最も大切なのは、相手が話し始めるまで待つこと（書評ベース） |
| **遮らない** | 話の途中で割り込まない（書評ベース） |
| **「なぜ？」は後回し** | 最初から「なぜ？」と問い詰めない。まずは話し切ってもらう（書評ベース） |
| **前提を問う** | 一人で考えると前提条件を固定してしまいがち。「本当にそれは変えられない前提なのか？」と問うのが壁の重要な役割（書評ベース） |
| **食い違ったら背景を探る** | 意見が違うときは「なぜそう思うのか」を聞き、前提や価値観の違いを言葉にする |
| **具体と抽象を行き来させる** | 抽象的な話に終始しがちなら具体的な話に、具体的な話に終始しがちなら抽象的な話に、転換を図る問いを立てるのが「壁」の役目（書評ベース）。具体へ：「たとえば？」「それは誰がやるの？」／抽象へ：「要するに、何が一番困っている？」「それができると、何がよくなる？」（問いの例は運営の作例） |
| **脱線したら確認する** | 「最初の〇〇の話に戻りますか？」と聞く。戻すかどうかは話し手が決める。脱線先が本当に気になっていることの場合もある（運営による補足） |

### NG行為

石川さんの考え方から読み取れる、聞き手がやってはいけないこと。

| NG | 理由 | 出典の扱い |
|---|---|---|
| 相手が話し始める前に口を出す | 「待つ」が最も大切 | 書評ベース |
| 話を遮る | 話し手の思考の流れが止まる | 書評ベース |
| いきなり「なぜ？」と問い詰める | 詰問になり、話し手が考えを出せなくなる | 書評ベース |
| 持論を語りすぎる・説教調になる | 壁打ちの効果を損なう。主役が聞き手に移る | 書評ベース |
| 正解を出さなければと気負う | 聞き手に答えを出す責任はない | インタビュー・記事 |
| 結論や承認を迫る | 壁打ちは結論を出すための場ではない | インタビュー |

> 以前の第6回ファイルにあった叩き台（「評価・採点する」「否定から入る」など）は、運営側で考えた案で、石川さんの出典はない。

## 6. よい壁の条件

- **知識・経験・発想力・人脈・権限があるだけでは、よい壁になれるとは限らない**
- その手前に「この人はちゃんと話を聞いてくれそうだ」と感じさせる要素が必要
- 人は**佇まい**で「この人は壁打ちのよい相手になってくれそう」と見分ける。石川さんは、HR分野の武田雅子さんの「リーダーとしてのたたずまい」という表現を引いている
- よい壁になれる人は、組織のキーパーソンになる
- 視野を広げたい（拡張したい）なら、自分と違う部署や職種の**「遠い人」**を相手に選ぶとよい（書評ベース）

## 7. 壁打ちの効果

**5つの効用（第3章、書評ベース）**：自覚・整理・俯瞰・確認・拡張

| 効果 | 内容 |
|---|---|
| 思考の解像度が上がる | 話すことで頭の中が整理され、アイデアが具体的になる |
| 人間関係ができる | 一度壁打ちをしただけで距離が縮まり、その後声をかけやすくなる |
| 部門間の壁を越える | 営業・製造・管理など異なる部署の人同士で壁打ちできる風土があると、アイデアの実現可能性が高まる |
| キーパーソンを味方にできる | 思考整理にとどまらず、組織の中で意見を通す手段にもなる |

**組織と上司について**

- かつては喫煙ルームや飲み会が、肩書を気にせず話せる「壁打ちの場」になっていた
- それらが減った今、上司には「よい壁打ち相手」であることが求められる
- 上司が「自分で考えろ」と言うだけでは、部下は考えを深めにくい

## 8. 第6回「壁打ち会」への活かし方（運営案）

> ここは石川さんの考え方をもとに、運営側で考えた案。

**実演（西村・尾上さん）で見せたいこと**

- 話し手が冒頭で「伝える3点」を言う
- 聞き手が待つ・遮らない・すぐ答えを出さない
- 聞き手が「それは誰がやるの？」「それは本当に変えられない前提？」のように具体や前提を問う
- 結論が出ないまま終わってもよいことを見せる

**ロープレの進め方**

- 話し手は、テーマ『事業計画実現に向けて、自分自身の業務の中で貢献・改善できること』について、冒頭で3点（状況・意図・期待）を一言ずつ伝えてから話し始める
- 聞き手は、NG行為の表を手元に置いておく
- 時間は1回10分程度（「数分〜十数分」という特徴に合わせる）

**フィードバックの観点**

| 立場 | 観点 |
|---|---|
| 話し手 | 話す前と後で、頭の中がどれくらい整理されたか。次にやることが見えたか |
| 聞き手 | 待てたか。遮らずに聞けたか。答えを出そうとしなかったか |
| 両方 | 相手のどの一言が効いたか |

**事業案なしの参加者向け**

- 「わからない」と言ってよい。専門外のことを聞くのだから当然
- 聞き手はうまい助言をしなくてよい。知識や経験がなくても、よい壁にはなれる
