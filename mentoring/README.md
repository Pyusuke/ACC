# 壁打ち・メンタリングについて

## 位置づけ

月1回の講座とは別に、週次で実施する個別・少人数でのセッション。
「教える場」ではなく、**「考えを引き出す場」**。

## 運営方針

- 答えを渡さない。問いを立てる
- 宿題を決める。次回冒頭で確認する
- ログは必ず残す（対話の内容を財産として蓄積する）

## ログの残し方

```bash
cp mentoring/logs/_template.md mentoring/logs/YYYY-MM-DD.md
```

ファイル名は実施日付で統一する。

## Claude Codeへの依頼例

```
mentoring/logs/2026-04-12.md を読んで、
ideas/idea_001/progress.md に追記すべき内容を
フォーマットに合わせて提案してください。
```

```
mentoring/logs/ 配下の直近3件のログを読んで、
各事業案の共通課題を抽出してください。
```
