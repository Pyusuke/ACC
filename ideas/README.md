## 新しい事業案フォルダの作り方

```bash
cp -r ideas/_template ideas/idea_001
```

ファイル名（`idea_001`）は任意。わかりやすい名前でもOK。
`ideas/kamameshi/` が記入済みのサンプルとして参考にできます。

## 各ファイルの役割

| ファイル | 役割 | 更新頻度 |
|---|---|---|
| `overview.md` | 事業サマリー（常に最新状態を保つ） | 毎回のセッション後 |
| `business_plan.md` | フォーマルな事業計画書（節目で更新） | セッション後・壁打ち後 |
| `progress.md` | 仮説の進化ログ（追記のみ。削除しない） | 壁打ち・セッションのたびに |
| `hypothesis.md` | 現時点の仮説一覧（随時書き換える） | 仮説が変わるたびに |

### overview.md と business_plan.md の使い分け

| | overview.md | business_plan.md |
|---|---|---|
| 目的 | 現在地の素早い把握 | 発表・共有向けの整理 |
| 粒度 | 要点のみ | 詳細・根拠まで記載 |
| 更新 | こまめに | セッションの節目で |
