## 2026-05-11｜MVV共有（第2回セッション冒頭）

**何が変わったか**

初期メモ段階から、MVVが言語化され、戦略の入り口（点検から始める）が明確になった。

**MVV（確定版）**

| 項目 | 内容 |
|---|---|
| Mission | 50年後の土木インフラを、日本全国もれなく豊かにする |
| Vision | 地方の暮らしを、より安全で豊かにする |
| Value | 技術の力で社会課題を解決する・労働人口減少や都市一極集中への対抗・地方創生への貢献 |

**タイトルの確定**

- 事業タイトル：点検から始まる簡単橋梁仮設システム（アプリッチ 2.0）
- タグライン：「未来の土木インフラの安心を支える」

**「点検から始める」という戦略の明確化**

更新・架替えを「売りに行く」のではなく、まず点検を提案する、という入り口設計が提示された。

背景にある論理：
```
地方では「人がいない・ニーズが顕在化しにくい」
  ↓
しかし点検を通じて課題を可視化できる
  ↓
「ここは更新が必要」「この先リスクがある」
  ↓
ニーズを顕在化させてから次のステップへ
```

**社会的背景の整理**

- 2040年には道路橋など土木インフラの約8割が供用年数50年超になる
- 都市部では更新工事が進む一方、地方では取り残されるインフラが多い
- 「全国もれなく」という言葉は地方格差への問題意識から来ている

**西村さんからのフィードバック（講義内）**

- 「社会課題 → 地域課題 → 橋梁 → 点検」というスケールの落とし方が明確
- 「50年後」「全国もれなく」という長期視点を持つことで、日々の業務の見え方も変わる
- 実業務の中で「これ、事業につながるのでは？」という気づきが出てくる状態になるはず

**次の問い**

- 「点検」から「更新提案」へつなぐプロセスの具体的な設計は何か
- 施工業者が「喜ぶ」施工容易性の具体的な仕様は何か（前回からの積み残し）
- 顧客（自治体・建設コンサル・施工業者）のうち誰が最初のターゲットか
- 収益をどの段階・誰から得るか

## 2026-05-11｜壁打ち実施（第2回セッション当日）

**何が変わったか**

「設計の省力化」が目的から手段へ再定義された。価値の出口を**施工**に置くという転換。

**最大の転換点：因果の逆転**

```
変更前：設計省力化 → 製作省力化 → 施工省力化（並列）

変更後：施工省力化（目的・顧客価値の出口）
          ↑
        設計省力化（施工を楽にするための手段）
```

**顧客の再定義**

| 役割 | プレイヤー | 変更 |
|---|---|---|
| 意思決定者（発注・予算） | 自治体 | 変わらず |
| 価値受益者（施工省力化の恩恵） | 工事業者・建設コンサル | **新たに特定** |

→ 「施工が楽になる便益」を直接受け取るのは施工を担うプレイヤー。
自治体は意思決定者だが直接の受益者ではない可能性がある。

**開発方針の合意**

- 廣田さんの開発テーマ（設計省力化）は変えない
- ただし常に「この設計省力化は施工をどう楽にするか」「誰の何が助かるか」を意識して進める

**次のアクション（合意済み）**

橋梁施工のバリューチェーンを社内ヒアリングで把握する：
- 設計 → 積算 → 発注 → 仮設 → 施工 → 検査・引き渡し
- どこに負荷が集中しているか・誰が困っているか・省力化が価値に変換されやすいポイントはどこか

社内に詳しい人がいるため、ヒアリング・整理は比較的容易。

**次の問い**

- バリューチェーンの中でボトルネックはどこか（ヒアリングで確認）
- 工事業者・建設コンサルが「払えるか・払うか」の感触はどうか
- 「点検から始める」戦略（MVVで設定）と「施工省力化」の価値軸はどう接続するか
