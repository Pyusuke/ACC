# プログラム全体設計

## コンセプト

「仮説を育てる場」

新規事業は最初から正解があるものではない。
このプログラムは、**完成した事業案を作ること**ではなく、
**仮説を検証・更新し続けるプロセスを体験すること**を目的とする。

## 参加者の前提

- 事業案あり・なし、どちらの参加者も受け入れる
- アイデアの完成度は問わない。「仮」でも構わない
- ピボットは失敗ではなく前進として扱う

## プログラムの構造

```
[種まき期]          [検討期]              [発表期]
アクセラ前 ──→ 第1〜5回（月次） ──→ 第6〜7回
                  ↕
          週次壁打ち・メンタリング
```

## 運営者の役割

- 教える人ではなく、**問いを立てる人**
- 事業案の良し悪しを判断する人ではなく、**思考を深める人**
- 参加者が自分の言葉で語れるようになるのを支援する

## 評価の考え方

最終発表の完成度よりも、
- 仮説がどう進化したか
- なぜそのピボットをしたか
- 自分の言葉で語れるか

を重視する。
